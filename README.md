# Gopichand | Scriptwriter & AI Video Creator Portfolio

A modern, responsive personal portfolio website for a freelance Scriptwriter and AI Video Creator. The site showcases services, content niches, a portfolio of work (scripts and AI-generated videos), and professional experience.

## Features

- **Hero Section**: Engaging introduction with dynamic elements and clear call-to-action buttons.
- **About Me**: Personal details, freelance handle, and information about the full script-to-video pipeline.
- **Services**: Highlights offerings like Script Writing, AI Video Production, Brand Content, and Content Packages.
- **Niches**: Visual grid of content niches (Storytelling, Facts, Motivational, Horror, etc.).
- **Portfolio**: Interactive, filterable gallery showcasing AI video projects and script samples.
- **Experience**: Timeline of professional journey and skills.
- **Contact Form**: Direct contact integration for potential clients.
- **Responsive Design**: Fully optimized for desktop, tablet, and mobile devices.

## Technologies Used

- **HTML5**: Semantic structure.
- **CSS3**: Custom styling, animations, responsive layouts (Grid & Flexbox).
- **Vanilla JavaScript**: Interactivity, portfolio filtering, dynamic canvas effects.

## Setup & Deployment

1. **Clone the repository:**
   ```bash
   git clone <your-repo-url>
   ```
2. **Open the project:**
   Navigate to the project folder and open `index.html` in any modern web browser. No local server or build tools are required to view the site.
